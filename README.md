# helm-postgres-ha 🐹

> 🧭 General-purpose highly available PostgreSQL Helm chart: streaming replication, lease-based failover with fencing, WAL-G backup and restore, and PgBouncer.

## 📦 Install

```bash
go get github.com/Bugs5382/helm-postgres-ha
```

## 🛠 Develop

```bash
task build    # go build ./...
task test     # go test ./...
task lint     # gofmt check + golangci-lint + yamllint
task license  # inject MIT headers (golic)
```
